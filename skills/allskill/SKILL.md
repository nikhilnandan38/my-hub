# /allskill: router for available skills

When invoked:
1. No argument or "list": show the skills below grouped by group, one line each.
2. A skill name or a request that matches one: tell the user which skill fits, then invoke it with the Skill tool using the exact name shown below.
3. A search term: show the skills whose name or description contains it.
4. A skill that is not listed: say so. Do not invent one.
